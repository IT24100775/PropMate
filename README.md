# \# PropMate

# 

# PropMate is an intelligent property rental, marketplace, and verification system developed as an integrated software engineering project.

# 

# The system combines a React web application, Flutter mobile application, ASP.NET Core Web API, PostgreSQL database, and component-specific AI agents.
